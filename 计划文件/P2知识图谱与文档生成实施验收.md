# P2 知识图谱与文档生成

日期：2026-10-16；补验日期：2026-10-19。

## 入口和使用

知识库列表 → 词条管理 →「知识图谱」或「从文档生成」。大画布弹窗的标题和标签固定，内部区域滚动。

图谱展示文档版本（蓝）、词条（青）、别名（橙）。文档与词条连线表示真实原文来源，词条与别名连线表示实际维护的别名，共享文档形成分组。支持搜索并保留相邻关系、显示/隐藏别名与标签、管理员切换未发布词条、点击节点查看定义/版本/原文、编辑词条、拖动画布、滚轮或按钮缩放、适应屏幕。

图谱复用词条列表的知识库鉴权与数据，不复制企业事实；读者没有未发布词条和生成入口。最多展示60个词条，每条5个别名，超过上限显示提示。

## 自动生成闭环

选择当前Release中的文档和负责人 → 生成章节预览 → 检查原文摘要及来源 → 选择候选 → 保存草稿 → 列表/图谱查看 → 编辑、送审与发布。

当前策略是确定性的章节抽取：识别Markdown标题及PDF明确的服务规范章节，摘要直接摘录原文，不调用模型推测事实。没有标题时以文档名生成一个候选。此实现是自动生成可审阅词条，尚非LLM自动实体、关系抽取或完整Ontology。

预览不写入；导入重新读取当前发布原文并重建候选。客户端不能指定任意定义或来源。发布版本变化返回409，未知候选400，非本库文档404。重复概念经过全半角、空格和末尾「规范」归一化后跳过；导入使用事务并生成快照和审计。

单文档最多600个片段、40个候选；每个候选最多关联30个片段，超过时提示截断。摘要最多1200字符，审核人员应打开原文检查完整性。草稿不会直接进入检索，必须走现有审核发布流程。
