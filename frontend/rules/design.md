关键特征：

- 克制、数据密集、任务优先。
- 登录页集中承载品牌表达，进入工作台后恢复安静的中性界面。
- 先保证信息可扫描、状态可判断、操作可预期，再考虑品牌识别。
- 所有规则均来自当前 Web 实现，不建立脱离代码的第二套设计系统。

## Colors

- `brand #7656C8`：主要动作、当前导航和图表主序列。
- `brandStrong #6242B5`：浅色背景上的品牌强调文字。
- `brandSoft #F0EBFF`：轻量品牌背景和选中反馈。
- `canvas #F7F5FC`：浅色工作台画布；深色模式对应 `#171420`。
- `ink #28243A`：浅色模式主要文字；深色模式对应 `#EEEAF7`。
- `statusUp oklch(0.62 0.16 151)`：健康、成功和正向变化。
- `destructive oklch(0.57 0.2 26)`：错误及危险操作。

普通页面使用 `background`、`card`、`foreground`、`muted-foreground`、`border`、`input` 和 `ring` 等语义变量。图表需要对比序列时，沿用当前实现中的蓝 `#4D83C7`、青 `#2F9B8F`、橙 `#DC8A35` 和玫红 `#D85F86`。紫色只表示当前、品牌或可执行，不作为无业务含义的装饰色。

## Typography

- 界面字体：`Avenir Next, Avenir, Segoe UI Variable, Segoe UI, sans-serif`。
- 等宽字体：`SFMono-Regular, Roboto Mono, Consolas, Liberation Mono, monospace`，只用于状态元信息、代码和编号。
- 登录品牌主标题：`48px / 700 / 1.12`。
- 登录表单标题：`30px / 700`。
- 页面标题：`24px / 700`。
- 区块标题：`16–20px / 700`。
- 正文与控件：`14px`；辅助标签：`12px`；导航分组：`11px`。

页面保持一条清晰标题链。中文使用系统字体自然回退，不额外引入 Web Font，不用全大写、超宽字距或字体混搭制造层级。

## Layout

- 工作台侧栏宽 `240px`，顶栏高 `64px`，主内容最大宽度 `1500px`。
- 主内容内边距为移动端 `16px`、`sm` 起 `24px`、`lg` 起 `28px`。
- 常用卡片与区块间距为 `12px`、`16px`、`20px`，卡片内容默认内边距 `20px`。
- `lg` 以下将固定侧栏切换为带深色遮罩的移动抽屉。
- 当前使用 Tailwind 默认断点：`sm 640px`、`md 768px`、`lg 1024px`、`xl 1280px`。
- 登录页在桌面使用 `1.05fr / 0.95fr` 双栏，品牌区内边距 `48px`，表单最大宽度 `448px`；移动端隐藏品牌面板。

页面按任务顺序组织：标题与主要动作、筛选或说明、业务结果。看板卡片一次回答一个问题，列表页不静默隐藏影响判断的字段。

## Elevation & Depth

卡片和面板使用 `1px` 语义边框与轻环境阴影：`0 1px 2px rgb(63 45 91 / 0.04), 0 8px 24px rgb(79 58 116 / 0.06)`。深度只用于区分画布、固定导航、卡片和临时抽屉，不制造悬浮装饰感。

登录品牌区可使用当前紫色渐变与 `28px` 细网格作为入口识别；业务页面保持纯色语义背景。一个容器不同时叠加强边框、强阴影和强背景反差。

## Shapes

- 基础半径：`6px`。
- 小型细节：`4px`。
- 输入框：`6px`。
- 按钮、卡片和导航项：`8px`。
- 独立品牌容器：最多 `12px`。
- Badge：胶囊形圆角。

形状保持紧凑和稳定。卡片不使用夸张大圆角，按钮不使用无依据的胶囊形，业务页面不加入光晕、玻璃拟态、渐变字或悬浮装饰图形。

## Components

- Button：默认高 `32px`，`sm 28px`，`lg 36px`，图标按钮 `32px`；提供 primary、outline、secondary、ghost、destructive 和 link。焦点使用 `3px` 半透明 ring，按下缩放至 `0.96`，禁用态透明度 `0.5`。
- Card：`8px` 圆角、`1px` 边框和 panel shadow；Header 最小高 `56px`，Content 内边距 `20px`。
- Input / Select：默认高 `36px`、`6px` 圆角、水平内边距 `12px`；焦点使用品牌边框与 `2px` 弱品牌 ring。登录单任务控件可使用 `48px` 高度。
- Badge：高 `20px`、`12px` 字号、胶囊形；颜色只表达标签类型或真实状态。
- SidebarNavigation：桌面固定 `240px`；当前项使用紫色背景和白色文字，非当前项使用中性文字与轻 hover，分组标题为 `11px`。
- LoginForm：桌面左侧为品牌叙事，右侧为手机号验证码任务；移动端只保留产品标识和表单。

通用组件放在 `src/components` 并依据组件能力命名。仅服务某个页面领域的业务组件放在 `src/views/<capability>/components`，不以业务名称污染全局组件目录。

常规颜色、边框和位移过渡约 `150ms`；侧栏位移、箭头旋转和状态刷新反馈沿用现有动效。状态刷新闪烁为一次性 `600ms`。`prefers-reduced-motion` 下将非必要动画压缩至近乎即时。

## Do's and Don'ts

Do：

- 使用现有语义变量和组件变体保持明暗主题一致。
- 每个页面明确当前对象、关键状态和一个主要动作。
- 使用品牌紫表达当前上下文、主要动作或图表主序列。
- 为加载、空数据、错误、成功和进行中状态提供明确反馈。
- 保持键盘焦点可见，表单标签常驻，图标按钮提供可识别名称。
- 让登录页承担品牌表达，让业务页面保持安静、清晰和高效。

Don't：

- 不为单个页面创建私有色板、私有字体体系或新的组件风格。
- 不用渐变、玻璃拟态、光晕、渐变字或装饰插画填充业务页面。
- 不用成功、警告或错误色丰富画面，它们只表达真实状态。
- 不把业务专属组件放入全局 `src/components`。
- 不在页面与统一请求层重复提示同一个接口错误。
- 不为未来需求预建未使用组件、抽象层或兼容性样式。
