## 6. 文档解析技术

| 文件类型 | 技术选型 | 说明 |
|---------|---------|------|
| **Markdown** | 直接读取 | 纯文本，无需特殊处理 |
| **PDF (文本版)** | pdfplumber | 提取文本、表格 |
| **PDF (扫描版)** | PaddleOCR | OCR 识别（按需） |
| **Word (.docx)** | python-docx | 提取段落、表格 |
| **Word (.doc)** | antiword + subprocess | 转换为纯文本 |
| **TXT** | 直接读取 | UTF-8 编码 |

### 文档解析示例

```python
# PDF 解析
import pdfplumber
def parse_pdf(file_path: str) -> str:
    with pdfplumber.open(file_path) as pdf:
        text = "\n".join([page.extract_text() or "" for page in pdf.pages])
    return text

# Word 解析
from docx import Document
def parse_docx(file_path: str) -> str:
    doc = Document(file_path)
    text = "\n".join([para.text for para in doc.paragraphs])
    return text

# .doc 解析（需要安装 antiword）
import subprocess
def parse_doc(file_path: str) -> str:
    result = subprocess.run(
        ["antiword", file_path],
        capture_output=True,
        text=True
    )
    return result.stdout
```

**Nginx 配置示例**：
```nginx
upstream fastapi_backend {
    server 127.0.0.1:8080;
}

upstream embedding_backend {
    server 127.0.0.1:8001;
    server 127.0.0.1:8002;
    server 127.0.0.1:8003;
}

server {
    listen 443 ssl http2;
    server_name your-domain.com;
    
    ssl_certificate /etc/letsencrypt/live/your-domain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/your-domain.com/privkey.pem;
    
    # 前端静态文件
    location / {
        root /usr/share/nginx/html;
        try_files $uri $uri/ /index.html;
    }
    
    # API 接口
    location /api/ {
        proxy_pass http://fastapi_backend;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
    
    # WebSocket
    location /ws/ {
        proxy_pass http://fastapi_backend;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }
}
```
